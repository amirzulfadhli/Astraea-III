# Core v0.2 development

Built on the reviewed, unmerged PR #1 foundation. PR #1 received two confidentiality fixes with regression tests: usage metadata is allowlisted and provider failures cannot supply internal error codes.

Implemented: transactional SQLite jobs/history, persistent event deduplication, revision checks, fenced execution leases, validated checkpoint restoration, completed-step reuse, uncertain-request reconciliation state, durable review/cancellation, and read-only GitHub/Obsidian Markdown snapshots with source commit/blob provenance.

The computational suite runs in the isolated cloud JavaScript runner. Native SQLite, subprocess crash/restart, multi-connection fencing, rollback and read-only HTTP/Markdown tests run in GitHub Actions on Node 22 and 24. Test databases are created only in the cloud runner's temporary directory and are removed after each test.

No laptop was accessed. No vault file was changed. Both PRs must remain unmerged pending approval.

Limits: an approved persistent cloud volume is still required for real jobs; SQLite and Node's sqlite module have platform/runtime constraints; no schema migration, cross-store dedupe, distributed lease service, uncertain-provider reconciliation adapter, memory store, live model adapter or vault/Git writer is enabled.

Next milestone: authenticated reconciliation of uncertain provider outcomes, operator recovery/inspection commands, persistent-volume backup/restore tests and read-only snapshot evaluation. Approved writes remain a separately gated later milestone.
